AL DÍA v2.23 — PROYECTO COMPLETO PARA RESUBIR A GITHUB

Este ZIP conserva la estructura Android completa.

RECOMENDADO:
1. Usá GitHub Desktop para evitar que GitHub Web coloque los archivos de las carpetas en la raíz.
2. Cloná el repositorio.
3. Reemplazá localmente su contenido por TODO el contenido del ZIP completo.
4. Confirmá que en la raíz existan:
   - app/
   - gradle/
   - .github/
   - build.gradle
   - settings.gradle
   - gradle.properties
5. Confirmá que NO aparezcan MainActivity.java, index.html o AndroidManifest.xml sueltos en la raíz.
6. Hacé Commit y Push.
7. Entrá en Actions > Compilar APK Al Día > Run workflow.

IMPORTANTE:
- Los workflows son manuales (workflow_dispatch), no se ejecutan por cada push.
- /build.gradle usa Android Gradle Plugin 8.13.2.
- GitHub Actions configura Gradle 8.13 directamente.
- /app/build.gradle corresponde a versionName 2.23.
- El workflow ejecuta lintDebug antes de assembleDebug.
