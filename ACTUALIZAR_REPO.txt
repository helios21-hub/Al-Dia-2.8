ACTUALIZAR AL DÍA v2.26

Para actualizar un repositorio existente de Al Día:
1. Reemplazar app/ por la carpeta app/ de este paquete.
2. Reemplazar build.gradle, settings.gradle y gradle.properties de la raíz.
3. Reemplazar .github/workflows/build-apk.yml y publicar-actualizacion.yml.
4. Conservar gradle/wrapper/gradle-wrapper.properties. El paquete no contiene gradle-wrapper.jar; los workflows usan Gradle 8.13 instalado por GitHub Actions.
5. Subir CAMBIOS_V2_25.txt y VALIDACION_V2_25.txt como referencia.
6. Ejecutar Actions > Compilar APK Al Día > Run workflow.
7. Confirmar que primero pase lintDebug y después assembleDebug.
8. Solo considerar la versión compilada cuando el workflow haya generado el artefacto Al-Dia-APK.

v2.26 mantiene applicationId com.aldia.app y la misma clave debug fija para permitir actualización sobre versiones anteriores compatibles.
Backup v25 continúa aceptando las estructuras anteriores; los campos nuevos de aprendizaje e historial son opcionales/migrables.
